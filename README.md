# Unideals — Campus Marketplace Landing Page

A modern, high-performance landing page for **Unideals** built with [Next.js](https://nextjs.org), React 19, TypeScript, and Framer Motion.

## Features

- **Interactive Dynamic Headline**: Responsive slogan with animated Lucide icon slots.
- **Glassmorphism Countdown Timer**: Real-time launch countdown with animated digit transitions.
- **Student Waitlist Subscription**: Smooth early access signup with validation and responsive UX.
- **Light & Dark Theme Switch**: Theme toggle with persistent state and custom radial gradients.
- **Vercel Deployment Ready**: Optimized for instant zero-config deployment on Vercel.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Production Build

```bash
npm run build
npm run start
```
